## Decision

**Decision:** JSON Schema 2020-12 is cross-language structural validation. AJV validates in React. Python validates the same schema. Pydantic is a typed Python runtime model.

## Consequences

- Accepted as a baseline decision on 2026-09-05. Change it only through a superseding ADR that links back here; never edit the decision text in place.
- Implementation features that depend on this decision cite `adr:0013` in their kg-source shards.
