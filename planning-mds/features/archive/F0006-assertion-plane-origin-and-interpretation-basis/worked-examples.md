# F0006 worked examples and boundaries

**Provenance:** Synthetic development examples; outside the frozen holdout. All outputs below are illustrative expectations, not observed runtime results. Phase: F0006 storage/contracts/checks/hooks, v0.1A. Runtime stories must reproduce them through the service and PostgreSQL in the later feature action.

Definitions: [glossary](../../../domain/glossary.md#assertion), [ADR-0075](../../../architecture/decisions/ADR-0075-versioned-assertion-semantics-and-admission.md). Structured payloads: [contract-examples.json](contract-examples.json), with a local schema path and expected validity per case. Candidate schema validation does not establish structural admission or truth.

| Example | Worked expectation | Boundary / failure | Owner and contract |
|---|---|---|---|
| EX-ASSERT-001 — claim dimensions | The continuing EX-GL-001 declarations claim has mode ASSERTED, origin DOCUMENT_INTERPRETATION, basis EXPLICIT and confidence 0.98. Each reloads independently with its evidence. | Another source's conflicting amount persists separately. INFERRED is a basis, not a fourth fact mode; confidence does not decide acceptance. Legacy MACHINE_EXTRACTION stays raw, with a labelled compatibility projection only. | S0001 AC1–AC7; assertion-record-v2; ADR-0035 |
| EX-ASSERT-002 — local source reference | A source's named contractor is a document-local reference used by an open statement; no canonical Entity is created. Its introducing quote contains its name. | An unlisted subject is UNKNOWN_REFERENCE. Another reference claiming the same normalized name in that document is NAME_CLAIMED_BY_ANOTHER; do not merge the references. References in another tenant/KB/document cannot be attached. | S0002 AC1/7, S0003 AC2/3; assertion-record-v2 entity_reference |
| EX-ASSERT-003 — open storage | EX-SEM-001's source phrase “subcontracts all tear-off work to” and object are retained with EXPLICIT basis, null predicate/release and a located quote. | Filling `relatedTo`, changing basis to INFERRED or sending it to FactSlot selection is refused. No open extraction/alignment executes. | S0002 AC1–AC6; assertion-record-v2; interpretation-result-v2 |
| EX-ASSERT-004 — grounding versus meaning | EX-SEM-005 normalizes case and adjacent-currency whitespace, locating the source's `$ 500,000` against the supplied `$500,000` quote with a mapping to original text. | A quote for $5,000,000 absent from the block yields QUOTE_NOT_IN_SOURCE. A genuine $500,000 quote accompanied by a misread 5,000,000 value passes structural grounding and still requires semantic review. | S0003 AC1/6/7; assertion-admission-result-v1; ADR-0065 |
| EX-ASSERT-005 — selector honesty | A unique normalized phrase in a DOCX paragraph maps to the original paragraph/run ranges. Qualified PDF regions, XLSX cells and CSV row/column selectors retain their native coordinates. | Two equal values in separate cells do not yield an invented unique span. Use a verified coarser selector or unresolved precision. A model-provided offset never makes the match authoritative. | S0003 AC6; server_evidence definition; ADR-0058 |
| EX-ASSERT-006 — outcomes | A complete item survives a truncated response; the protected result includes TRUNCATED_OUTPUT and requires_partial=true for F0016. An undeclared object name in the quote becomes a literal plus OBJECT_UNDECLARED signal. | No parsable block yields BLOCK_UNINTERPRETED; affected missingness must become NOT_PROCESSED, not NOT_FOUND. A missing time reference is UNKNOWN_REFERENCE; time words outside the assertion quote are TIME_NOT_IN_QUOTE. F0006 does not claim durable drop rows were written. | S0003 AC3–AC5; admission-result outcome definition; F0016 consumer |
| EX-ASSERT-007 — mood and issued terms | EX-SEM-007's “Binding is subject to receipt …” retains `mood: "subject to"` and cannot assert that the application arrived. | An issued policy's operative provision is a claim about the policy having a condition. It does not establish that the insured meets it. A legacy correction cannot remove the source mood to bypass the guard. | S0004 AC1–AC3; qualifier schema; ADR-0065 |
| EX-ASSERT-008 — origin | EX-SEM-006's model-described chart value retains DESCRIBED origin and requires DESCRIBED_EVIDENCE review; it cannot auto-accept, close or supersede a stated limit. | Qualified OCR/transcribed text is admissible at actual precision. Legacy/unqualified support cannot be called qualified STATED or used as a token non-described item to clear described-only restrictions. | S0004 AC4–AC6; server_evidence and blocked_operations; F0004 source |
| EX-ASSERT-009 — additive compatibility | A v1 result replays with the same claim/evidence IDs; a review correction appends a linked child and retains original history. A v2 write adds a semantic extension. | Changed ID/hash replay fails; a crash before review insertion rolls back claim/evidence/names too. An old reader refuses v2 instead of stripping fields. Guard checks include mixed evidence and correction ancestors. | S0005 AC1–AC7; all three schemas; ADR-0075 |
