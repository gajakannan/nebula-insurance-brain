    fix(ci): load the engine pytest config in the F0011 contract steps
    
    The contracts unit/install step and the PostgreSQL consumer step run pytest from
    the repository root, so the root pyproject.toml (no asyncio_mode) was selected
    and 8 async tests failed as "async def functions are not natively supported".
    Pass -c engine/pyproject.toml, as every local evidence lane already does.
    Reproduced in an image built from a clean clone: 8 failed / 535 passed before,
    543 passed after. coverage-report.yaml regenerated for the workflow change.
